# Contributions back to the community

No fix of our own for the game is pending. This launcher's code is the
RetroArch configuration writer, the looks and the Linux/Hyprland scale
guard; none of that patches the game or belongs in a PCGamingWiki page.

- **No ROM patch, crack or DRM workaround.** The launcher only writes a
  private emulator configuration.
- **The Hyprland fractional-scale recipe** (set the focused monitor to
  scale 1 while a fullscreen RetroArch runs, restore on exit) is a launcher
  integration detail, not a game fix; it is documented in
  `linux/README.md` instead of a community patch.
- If a game fix is found later, add a draft here with an id (`C1`, ...), as
  `sdk/docs/playbooks/contribute-back.md` asks. Never post it without the
  owner's approval.
